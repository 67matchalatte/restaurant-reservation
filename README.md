# Restaurant Reservation — бронь столиков в ресторане
Проект команды 3 курса «Прикладная информатика» по дисциплине «Программная инженерия», осень 2026/2027.
Основа — индивидуальная работа А. Исаевой (курс «Проектирование ИС»).

## Проблема и пользователи
Рестораны принимают брони по телефону и в мессенджерах — администратор
тратит время на ручную запись, возможны накладки (двойная бронь, потеря
заявки). Пользователи системы:
- **гости ресторана** — хотят быстро забронировать столик онлайн;
- **администратор** — управляет бронями, видит загрузку зала;
- **менеджер ресторана** — настраивает зал, столики, часы работы.

## Ключевые функции первого релиза
- просмотр свободных столиков на выбранную дату и время;
- оформление брони с указанием имени и телефона гостя;
- отмена брони гостем;
- схема зала с визуальным отображением занятых столиков.
