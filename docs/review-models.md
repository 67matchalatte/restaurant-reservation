# Ревью моделей предметной области (чек-лист ЛР-5, табл. 2)

Базовая модель: Буркова Т.В. (UC + классы) с заимствованиями.
Дата ревью: 21.10.2026. Ревьюеры: Исаева А.Д., Гималова П.А.

## Чек-лист

### 1. Полнота (каждое требование/история ЛР-4 отражено в прецеденте или классе?)
- [x] ФТ-1, ФТ-2, ФТ-3 → прецедент «Просмотр каталога» + класс «Схема зала»
- [x] ФТ-4, ФТ-5, ФТ-6 → прецедент «Оформление брони» + классы «Бронь», «Столик»
- [x] ФТ-7, ФТ-8, ФТ-9 → прецедент «Управление своей бронью» + класс «Гость»
- [x] ФТ-10…ФТ-13 → прецедент «Управление бронями» + класс «Администратор»
- [x] ФТ-14 → прецедент «Настройка схемы зала» (менеджер)
- [x] ФТ-15 → прецедент «Настройка часов работы» (менеджер) — ДОБАВЛЕН по ревью
- [ ] **Замечание 1:** класс «Менеджер» отсутствует в базовой модели, хотя ФТ-14, ФТ-15 его требуют. → задача №31
- [ ] **Замечание 2:** нет прецедента «Настройка часов работы» → задача №32

### 2. Непротиворечивость (нет пересекающихся прецедентов и дублирующих классов?)
- [ ] **Замечание 3:** «Каталог столиков» и «Схема зала» дублируются (в ЛР-4 экран 1 и экран 3).
  → объединить в «Просмотр зала» с двумя режимами (список/схема). → задача №33
- [x] Классы «Гость» и «Администратор» не пересекаются (разные роли).

### 3. Кратности и связи
- [ ] **Замечание 4:** у связи «Гость — Бронь» стоит 1..1, а по ФТ-9 нужна история броней → 1..*.
  → задача №34
- [ ] **Замечание 5:** у «Столик — Бронь» стоит *..* без учёта времени. Для ФТ-5 (проверка свободен
  на время) нужна связь через «Слот времени» или атрибут времени с ограничением. → задача №35
- [x] «Бронь — Столик»: один столик — много броней во времени (реалистично).

### 4. Тестируемость (можно ли для каждого прецедента сформулировать критерий приёмки?)
- [x] Все прецеденты гостя покрыты критериями приёмки ЛР-4.
- [ ] **Замечание 6:** у прецедента «Настройка часов работы» нет критерия приёмки в ЛР-4.
  → задача №36 (дополнить историю 8 критерием).

### 5. Реализуемость (не требует ли модель экзотических механизмов?)
- [x] Модель реализуема на веб-стеке; экзотики нет.
- [x] 20 столиков, 50 запросов — в пределах обычного веб-приложения.
