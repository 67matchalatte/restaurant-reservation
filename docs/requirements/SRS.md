# SRS — Спецификация требований

## Функциональные требования

**ФТ-1.** Система должна отображать список свободных столиков на выбранную дату и время.

**ФТ-2.** Система должна фильтровать столики по количеству гостей.

**ФТ-3.** Система должна отображать схему зала с занятыми и свободными столиками.

**ФТ-4.** Система должна позволять гостю оформить бронь с указанием имени, телефона, даты, времени и числа гостей.

**ФТ-5.** Система должна проверять, что выбранный столик свободен на указанное время.

**ФТ-6.** Система должна присваивать каждой брони уникальный номер.

**ФТ-7.** Система должна отображать гостю статус его брони («ожидает», «подтверждена», «отклонена», «отменена»).

**ФТ-8.** Система должна позволять гостю отменить свою бронь.

**ФТ-9.** Система должна отображать гостю историю его броней.

**ФТ-10.** Система должна отображать администратору список всех броней с фильтром по дате и статусу.

**ФТ-11.** Система должна позволять администратору подтверждать бронь.

**ФТ-12.** Система должна позволять администратору отклонять бронь.

**ФТ-13.** Система должна позволять администратору редактировать данные брони.

**ФТ-14.** Система должна позволять менеджеру добавлять столики в схему зала.

**ФТ-15.** Система должна позволять менеджеру настраивать часы работы ресторана.
