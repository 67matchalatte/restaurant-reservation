# Протокол перекрёстного ревью требований

**Дата:** 14.10.2026
**Ревьюеры:** команда «Меню» 
**Проверяемые артефакты:** ФТ, НФТ, пользовательские истории

## Чек-лист ревью

- **Атомарность** — одно требование = одно действие.
- **Однозначность** — нет двусмысленных формулировок.
- **Проверяемость** — можно превратить в тест.

## Замечания и их закрытие

### Замечание 1. ФТ-4 — составное требование

**Замечание:** ФТ-4 «Система должна позволять гостю оформить бронь с указанием имени, телефона, даты, времени и числа гостей» — перечисляет несколько полей. Возможно, стоит разделить.

**Решение:** оставлено как есть. Требование описывает **одно действие** — оформление брони, а поля — это детали. Разделение не требуется.

**Статус:** закрыто (принято без изменений).

### Замечание 2. НФТ-3 — «в часы работы ресторана» неоднозначно

**Замечание:** НФТ-3 «Система доступна не менее 99% времени в часы работы ресторана» — не указано, какие именно часы.

**Решение:** уточнено — «в часы работы ресторана (с 10:00 до 23:00)».

**Статус:** закрыто (требование уточнено).

### Замечание 3. История 4 — нет второго критерия приёмки

**Замечание:** у Истории 4 (просмотр истории броней) только один критерий приёмки. Добавить второй — для случая, когда броней нет.

**Решение:** добавлен критерий:
> Дано: у гостя нет броней. Когда: открывает раздел. Тогда: показывается сообщение «у вас пока нет броней».

**Статус:** закрыто (критерий добавлен).

### Замечание 4. ФТ-7 — перечисление статусов

**Замечание:** ФТ-7 «Система должна отображать гостю статус его брони (ожидает, подтверждена, отклонена, отменена)» — перечисление статусов не является частью требования.

**Решение:** оставлено, так как перечисление помогает понять, какие статусы бывают. Не нарушает атомарность.

**Статус:** закрыто (принято без изменений).

## Итог

Все замечания закрыты. Требования соответствуют чек-листу:
- атомарность — ✅;
- однозначность — ✅;
- проверяемость — ✅.
