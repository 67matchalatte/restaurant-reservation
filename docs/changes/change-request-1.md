# ЗИ-1: Добавить фильтр по расположению столика

**Дата:** 14.10.2026
**Автор:** Гималова П.

## Описание изменения

Добавить в каталог столиков фильтр по расположению: «у окна»,
«около входа», «по середине зала».

## Причина

Гости часто просят столик у окна. Фильтр ускорит выбор.

## Оценка влияния

- **На срок:** +3 часа на доработку каталога.
- **На архитектуру:** затронет страницу каталога и запросы к БД.
- **На другие требования:** ФТ-1, ФТ-2.

## Решение

**Принято.** Владелец продукта счёл функцию полезной и не критичной
по срокам.
