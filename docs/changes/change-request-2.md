# ЗИ-2: Добавить чат с гостями

**Дата:** 14.10.2026
**Автор:** Исаева А.

## Описание изменения

Добавить в кабинет администратора чат с гостями для уточнения деталей.

## Причина

Гость мог бы уточнить детали брони без звонка.

## Оценка влияния

- **На срок:** +20 часов на разработку чата.
- **На архитектуру:** потребует WebSocket-сервер, хранение сообщений,
  интеграцию с фронтендом.
- **На другие требования:** НФТ-1 (производительность), НФТ-5
  (безопасность).

## Решение

**Отклонено.** Функция выходит за рамки MVP, требует значительных
затрат и усложняет архитектуру. Может быть рассмотрена в следующей
версии.
