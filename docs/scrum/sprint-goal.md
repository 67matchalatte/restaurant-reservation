# Цель первого спринта

**Спринт 1 — базовый функционал брони**
**Дата:** 30.09.2026 — 14.10.2026 (2 недели)

## Цель спринта

Реализовать базовый сценарий бронирования: гость может найти
свободный столик, оформить бронь и при необходимости отменить её.

## Задачи спринта

| ID | Задача | Оценка (ч) | Ответственный |
|----|--------|-----------|---------------|
| 1 | Каталог столиков | 8 | Гималова |
| 2 | Форма оформления брони | 6 | Гималова |
| 3 | Отмена брони гостем | 4 | Исаева |
| **Итого** | | **18 ч** | |

## Критерий готовности спринта

- гость может открыть каталог и увидеть свободные столики;
- гость может оформить бронь через форму;
- гость может отменить свою бронь;
- все три задачи прошли проверку и приняты владельцем продукта.
