# Протокол выбора базовой модели предметной области

Дата: 21.10.2026
Участники: Буркова Т.В., Исаева А.Д., Гималова П.А.

## Рассмотренные индивидуальные варианты (из дисциплины ПИС)

1. **Буркова Т.В.** — «Бронь столиков в ресторане»: UC-модель + диаграмма классов.
   Прецеденты: бронирование, отмена, просмотр каталога, управление бронями (админ).
   Классы: Гость, Администратор, Столик, Бронь, Ресторан, Схема зала.
2. **Исаева А.Д.** — «Запись в ветеринарную поликлинику»: ER-first подход.
3. **Гималова П.А.** — «Запись в барбершоп»: UC-модель.

## Решение

За основу взята модель **Бурковой Т.В.**, так как:
- прецеденты полнее покрывают бэклог ЛР-3 (17 историй, 5 эпиков);
- присутствуют связи include/extend (подтверждение брони extend оформление);
- классовая модель согласуется с прототипом ЛР-4 (Столик, Бронь, Гость, Администратор).

## Заимствования из альтернатив
- Из варианта Исаевой А.Д. взята идея сущности **«Расписание/Часы работы»**
  (для ФТ-15 «Настройка часов работы») — в базовой модели её не было.
- Из варианта Гималовой П.А. взята связь **«Столик — Схема зала»** (агрегация),
  полезная для ФТ-3 и ФТ-14.
