# Тест-дизайн: функция создания брони (`create_booking`)

Для проектирования тестов использованы методы «чёрного ящика»: классы эквивалентности и граничные значения для параметров функции.

## Таблица классов эквивалентности и граничных значений

| Параметр | Класс/Граница | Входное значение | Ожидаемый результат |
| :--- | :--- | :--- | :--- |
| **Дата** | Прошедшая дата | "2020-01-01" | Ошибка ("прошедшую дату") |
| | Сегодняшняя дата | `date.today()` | Успех (если слот свободен) |
| | Будущая дата | "2030-01-01" | Успех (если слот свободен) |
| | Неверный формат | "завтра" | Ошибка ("Некорректная дата") |
| **Телефон** | Валидный (10 цифр) | "+7999123456" | Успех |
| | Валидный (15 цифр) | "+799912345678901" | Успех |
| | Слишком короткий (9 цифр)| "+799912345" | Ошибка ("от 10 до 15 цифр") |
| | Слишком длинный (16 цифр)| "+7999123456789012" | Ошибка ("от 10 до 15 цифр") |
| | Буквы вместо цифр | "телефон" | Ошибка ("от 10 до 15 цифр") |
| **Гости** | 1 гость (мин. граница) | 1 | Успех (для столика на 2) |
| | 2 гостя (макс. для столика) | 2 | Успех (для столика на 2) |
| | 3 гостя (превышение) | 3 | Ошибка ("от 1 до 2 гостей") |
| | 0 гостей (нижняя граница) | 0 | Ошибка ("от 1 до 2 гостей") |
| | Отрицательное число | -1 | Ошибка ("от 1 до 2 гостей") |
| **Имя** | Валидное | "Иван" | Успех |
| | Пустая строка | "" | Ошибка ("Укажите имя") |
| | Пробелы | "   " | Ошибка ("Укажите имя") |
| **Время (слот)**| Валидный слот | "18:00" | Успех |
| | Невалидный слот | "19:00" | Ошибка ("Ресторан работает...") |
