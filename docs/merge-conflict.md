# Отчет о разрешении конфликта слияния

В ходе выполнения ЛР-6 было проведено моделирование конфликта слияния в Git.

## Шаги воспроизведения и разрешения:
1. В ветке `feature/conflict-a` в файл `README.md` была добавлена строка «Тестовая строка для конфликта А». Ветка была слита в `main`.
2. В ветке `feature/conflict-b` (созданной от `main`) в ту же область файла была добавлена строка «Тестовая строка для конфликта Б».
3. При попытке создать Pull Request из `feature/conflict-b` в `main` GitHub обнаружил конфликт (CONFLICT в `README.md`).
4. С помощью веб-интерфейса GitHub («Resolve conflicts») файл был открыт. В нем отображались маркеры конфликта (`<<<<<<<`, `=======`, `>>>>>>>`).
5. Было принято решение сохранить обе строки (историю изменений). Маркеры конфликта были удалены вручную.
6. После сохранения изменений и нажатия «Mark as resolved» конфликт был успешно разрешен, PR смержен в `main`.
