# Релизный план

Релизный план распределяет истории по выпускам на основе
приоритетов (MoSCoW) и мощности команды (velocity ≈ 16 ч за спринт).

## Релиз v0.1 (MVP) — неделя 8, демо прототипа

**Цель:** работающий прототип с полным сценарием бронирования.

| ID | История | Оценка (ч) |
|----|---------|-----------|
| 1 | Список свободных столиков | 5 |
| 4 | Оформление брони онлайн | 6 |
| 5 | Подтверждение брони гостем | 3 |
| 8 | Список всех броней (админ) | 6 |
| 9 | Подтверждение брони (админ) | 4 |
| 10 | Отклонение брони (админ) | 4 |
| **Итого** | | **28** |

28 ч > velocity (16 ч) → MVP требует **2 спринта**.
