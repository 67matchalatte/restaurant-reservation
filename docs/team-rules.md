# Правила команды

Документ фиксирует Definition of Ready и Definition of Done —
критерии, по которым команда берёт истории в работу и закрывает их.

## Definition of Ready (DoR)

Историю можно взять в спринт, если:

1. **Ценность сформулирована** — понятно, какую проблему решает
   история и для какой роли.
2. **Есть критерии приёмки** — описано, как проверить, что готово.
3. **История оценена** — команда понимает её размер (в часах).
4. **История умещается в спринт** — оценка не превышает velocity.
5. **Зависимости учтены** — понятно, от чего зависит история.

## Definition of Done (DoD)

Историю можно считать готовой, если:

1. **Код написан и работает** — функция реализована, проверена вручную.
2. **Критерии приёмки выполнены** — все пункты «Дано–Когда–Тогда» соблюдены.
3. **Изменения в репозитории** — код залит через pull request и прошёл ревью.
4. **Задача в трекере обновлена** — статус изменён на «Готово».
5. **Документация обновлена** — если история затрагивает docs/, изменения внесены.

## Применение

- **Перед планированием спринта:** команда проверяет каждую историю
  по DoR. Если история не готова — возвращается в бэклог.
- **При завершении истории:** команда проверяет её по DoD.
  Если что-то не выполнено — история не закрывается.
