# Эскизный прототип интерфейса

Прототип содержит 4 ключевых экрана. Каждый экран обслуживает
определённые пользовательские истории.

## Экран 1. Каталог столиков (гость)

**Обслуживает:** История 1 (просмотр свободных столиков).
**Файл:** `screen1-catalog.png`

## Экран 2. Форма брони (гость)

**Обслуживает:** История 2 (оформление брони).
**Файл:** `screen2-booking.png`

## Экран 3. Схема зала (гость)

**Обслуживает:** История 3 (схема зала с занятостью).
**Файл:** `screen3-hall.png`

## Экран 4. Кабинет администратора

**Обслуживает:** Истории 5, 6, 7 (список, подтверждение, отклонение).
**Файл:** `screen4-admin.png`
